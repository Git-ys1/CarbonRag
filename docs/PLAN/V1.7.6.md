# V1.7.6 Super Admin Web SSH Terminal

## 目标

把 super admin 控制台里的 Web SSH 从占位状态推进到可用的后端代理终端。

## 实现口径

- 浏览器不直接调用本机终端，也不接收 SSH 密钥或密码。
- 前端通过 `/api/v1/management/ssh-terminal/ws` 建立 WebSocket。
- 后端在受信主机上启动 PTY 子进程，默认命令由 `WEB_SSH_COMMAND` 控制。
- 本地开发可设置 `WEB_SSH_COMMAND=ssh carbonrag-vps`，打开终端后自动进入 `ssh carbonrag-vps`。
- VPS 部署可设置为本机 shell 或受控维护脚本，避免在服务器上再次 SSH 自己。

## 权限要求

- 仅 `super_admin` 可见。
- 必须已建立 active SA Relay。
- 必须启用 `ENABLE_WEB_SSH_TERMINAL=true`。
- WebSocket 握手必须通过 Origin 检查、Cookie session 校验和 super admin 角色校验。
- 输入命令按行写入 management audit log，包含敏感词的输入会被脱敏。

## UI 调整

- super admin 页面顶部卡片显示 Web SSH 状态和当前命令。
- Web SSH 终端模块上移到管理员恢复申请之前。
- 旧 admin 恢复申请降级为兼容区；新管理员账号仍建议由 super admin 主动创建。

## 配置

```env
ENABLE_WEB_SSH_TERMINAL=false
WEB_SSH_COMMAND=ssh carbonrag-vps
WEB_SSH_MAX_SESSION_SECONDS=3600
```

生产环境必须只在可信后端主机启用，并确保 super admin 设备签名、Relay 与审计链路均正常。
