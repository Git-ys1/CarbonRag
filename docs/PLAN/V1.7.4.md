# V1.7.4 Management Policy V1.2 Super Admin Relay Hardening

## Summary

本轮目标是把现有 management skeleton 加固为可真实联调的管理安全 baseline。普通业务不参与 Management Relay；admin 后台走 `AD_HELLO`，super_admin 后台走 `SA_HELLO`；高风险修改动作必须走一次性 `ACTION_ACK`。

服务器联调由本地授权终端执行。SSH 凭据只在运行时使用，不写入仓库、文档、日志、脚本或 `.env.example`。

## Scope

- 新增管理政策与协议文档。
- 接入真实 WebCrypto 设备密钥和 ECDSA P-256 验签。
- 持久化 nonce，拒绝重放。
- 约束 super_admin 唯一设备和单 Relay。
- ACTION_ACK 绑定动作、目标和 payload hash，并一次性消费。
- 管理接口分级接入 active relay / ACTION_ACK。
- SuperAdminPage 支持设备登记、SA Relay、审计和受控运维面板。
- 新增 VPS 部署脚本目录 `deploy/management-v1.7.4/`。

## Non-goals

- 不做浏览器裸 SSH 终端。
- 不把服务器 SSH 凭据写入 Git。
- 不改变普通业务页面权限。
- 不纳入未跟踪的 `docs/碳核算专项/`、`演示/`、`docs/PLAN/V1.7.2B.md`。

## Acceptance

- 假签名不再通过。
- 重复 nonce 返回 409。
- 高风险 admin 接口无 ACTION_ACK 返回 403。
- ACTION_ACK 只能消费一次。
- user 不能访问 management 路由。
- SuperAdminPage 能登记设备、发 SA_HELLO、维持 Relay heartbeat。
- 受控运维命令必须 super_admin + SA Relay + ACTION_ACK + 二次确认。
- VPS 部署脚本支持备份、拉取、依赖、迁移、重启和 health check。
